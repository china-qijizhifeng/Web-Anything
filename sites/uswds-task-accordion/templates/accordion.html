Guidance

When to use the accordion component

  • If users will only need a few specific pieces of content within a page.
  • If you have only a small space to display a lot of content.

When to consider something else

  • If users need to see most or all of the information on a page. Use well-formatted text instead.
  • If there is not enough content to warrant condensing.

Usability guidance

Make the entire header selectable. Allow users to click anywhere in the header area to expand or collapse the content; a larger target is easier to manipulate.

Accessibility guidance

Code header areas in the accordion as buttons. Use meaningful expansion button labels and connect each button to its content with aria-controls.

Using the accordion component

  • Multiselectable accordion groups. Add the data-allow-multiple attribute to any usa-accordion to create a multiselectable accordion group.
  • Default an accordion button to open. Add the aria-expanded="true" attribute to any usa-accordion__button to have that section open by default at page load. When the accordion is initialized, JavaScript adds aria-expanded="false" to the other buttons.
  • Accordion icon position. The expand/collapse icon defaults to the start side of the accordion. “Start” refers to the reading order of the language — this means for languages that are read left to right (English, Spanish, etc.), the expand/collapse icon will default to the left. For languages that are read right to left (Arabic, Hebrew, etc.), the expand/collapse icon will default to the right. Previous to USWDS 3.14.0, the icon defaulted to the end side.
  • Set icon position. To change accordion icon placement everywhere an accordion appears, use the $theme-accordion-icon-position setting ("start" or "end"). To change icon placement for a single accordion, add usa-accordion--icon-start or usa-accordion--icon-end to the accordion root.

Accordion variants

The preview above shows a borderless group, a bordered group, and a multiselectable group. In the bordered example, opening “Second Amendment” reveals its text and list.

For accessible behavior, each header is a button with a unique aria-controls target. The controlled panel becomes visible when aria-expanded changes to true.
