Test the accordion in your project

USWDS tests components in isolation. You need to test the accordion component in the context of your own site to ensure compliance with Section 508 accessibility standards.

  • Use the checklist below.
  • Follow the “how to test” instructions for each type of assistive technology.
  • Anyone can test for accessibility.
  • These quick manual tests don’t require special equipment.

Zoom magnification tests

USWDS performed these tests to check accordion accessibility and usability for zoom magnification.

No need to scroll horizontally when screen is magnified.

When you zoom to 200%, accordion panels do not require horizontal scrolling.

WCAG AA 1.4.4 Resize text · USWDS test status: Passed · Last test: v3.5.0

Focus indicator is clear when screen is magnified.

When you zoom to 200% and navigate through items with the tab key, each item has a focus highlight that is clear and visible.

WCAG AA 1.4.4 Resize text · USWDS test status: Passed · Last test: v3.5.0

Content does not get cut off or overlap when screen is magnified.

When you zoom to 200%, no content is cut off, overlaps, or is obscured by other page elements.

WCAG AA 1.4.4 Resize text · USWDS test status: Passed · Last test: v3.5.0

Keyboard navigation tests

USWDS performed these tests to check accordion accessibility and usability for keyboard navigation.

Interactive elements work after tabbing.

When you use the tab key to navigate into an open accordion panel, each interactive item inside that panel is selectable.

WCAG A 2.1.1 Keyboard · USWDS test status: Passed

Accordion panel opens and closes with keyboard interaction.

Using the enter key or spacebar on a panel header toggles the panel, while hover and focus alone do not.

WCAG A 2.1.1 Keyboard · USWDS test status: Passed

Focus moves forward and backward in a logical order.

Tab and shift + tab move through visible focusable items without skipping them, and focus stays on the panel header after toggling.

WCAG A 2.4.3 Focus order · USWDS test status: Passed

Focus indicators are clear.

The accordion panel and interactive items inside it have a clear, visible focus highlight.

WCAG AA 2.4.7 Focus visible · USWDS test status: Passed

Screen reader tests

USWDS performed these tests to check accordion accessibility and usability for screen readers.

Focus moves in a logical order when using a screen reader.

The virtual cursor moves from one panel header to the next in a logical order.

WCAG A 2.4.3 Focus order · USWDS test status: Passed

Heading levels are logical and consistent.

Test heading levels in the context of your page and keep each accordion panel heading at the same level.

WCAG AA 2.4.6 Headings and labels · USWDS test status: Conditional

Screen reader announces collapsed and expanded states.

Screen readers announce the current panel state and the changed state after using enter or spacebar.

WCAG A 1.3.1 Info and relationships · USWDS test status: Passed
