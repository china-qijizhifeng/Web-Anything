# Coupled site requirements

- Reconstruct the official desktop information architecture and the major
  source-grounded route families found during bounded exploration.
- Exercise every visible first-order control with real browser clicks. A dead
  control, placeholder link, or generic leave-site notice is a failure.
- When the source exposes an account entry, implement a fictional local login,
  protected state, logout, persistence, negative authentication, and reset.
- Keep CSS, fonts, images, icons, and media local. The released runtime must
  produce no external requests, missing resources, console errors, or overflow.
- Use deterministic fixtures and SQLite-backed mutations. Reset must restore
  the exact seed state and evaluator results must distinguish success/failure.
- Compare the major local routes to usable official source renders at the
  configured desktop viewport; HTTP 200 or a similarity score alone is not
  sufficient.
