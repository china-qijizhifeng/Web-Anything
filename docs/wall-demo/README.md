# Website Wall assets

The interactive wall uses the frozen October 9, 2026 environment inventory:

- `environment-pool.js` contains metadata for 244 site artifacts across 14 application domains.
- `assets/environment-pool/` contains 244 JPEG previews downsampled to 480 × 333 pixels.
- `assets/environment-pool-large/` contains 42 curated 960 × 667 previews loaded only when a featured panel is inspected.
- The default wall displays 42 distinct inventory sites plus two repository evidence states. It does not count repeated spatial panels as additional sites.

These previews document observed reconstructed homepages. A homepage image and an HTTP 200 startup record do not establish complete functional acceptance. The full-resolution 1440 × 1000 capture archive, reconstructed source trees, and third-party media bundles are not included in this repository.
