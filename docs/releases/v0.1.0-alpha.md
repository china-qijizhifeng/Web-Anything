# WebAnything v0.1.0-alpha

This first alpha packages WebAnything as a reproducible research codebase for
constructing executable, resettable Web-agent environments from source-site
evidence.

## Included

- one-command provider and agent-skill setup through `webanything setup`;
- task-driven JIT and broader Full reconstruction entry points;
- source capture, grounded reconstruction, independent browser verification,
  repair, candidate freezing, reset checks, and release gates;
- a frozen metadata inventory for 244 historical site artifacts without their
  complete source trees or third-party media;
- runnable USWDS and Mermaid task demonstrations with third-party notices;
- English and Simplified Chinese documentation;
- reproducible Python and Node dependency locks and continuous integration.

## Validation

- zero open Dependabot alerts at the release candidate commit;
- 169 package and pipeline tests passed, with 6 environment-specific skips;
- 54 standalone Interaction Verifier tests passed;
- Node trace utility tests passed;
- package compilation, `webanything doctor`, the 244-site manifest check, and
  the release scan passed.

## Alpha limitations

- model-provider credentials and a compatible Responses API are required for
  real builds;
- JIT verifies the requested task path, while Full coverage is bounded by what
  can be discovered and observed;
- generated pages are not considered complete until independent verification
  and the release gate pass;
- users must have permission to inspect, reconstruct, and redistribute source
  site content and assets;
- historical `webharbor-*` schema identifiers remain for compatibility with
  frozen evidence.

See the [README](../../README.md), [architecture](../architecture.md), and
[known limitations](../limitations.md) before using the alpha.
